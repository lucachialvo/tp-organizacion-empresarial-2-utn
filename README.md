# TP Organización Empresarial 2 - Análisis de Ventas

## Integrante

Luca Joaquin Chialvo

## Escenario elegido

Escenario B – Análisis de Ventas de una Pequeña Empresa

## Descripción del proyecto

Este proyecto tiene como objetivo realizar un análisis básico de datos de ventas utilizando Python, Google Colab, GitHub y Jira.

El análisis permite procesar un conjunto de datos comerciales para obtener indicadores simples del desempeño de ventas y generar una visualización gráfica de los resultados.

## Dataset utilizado

Se utilizó un dataset de ventas simulado en formato CSV, almacenado dentro de la carpeta `/datos`.

El dataset contiene información sobre:

- fecha de venta
- producto
- cantidad vendida
- precio unitario

## Tecnologías utilizadas

- Python
- Pandas
- Matplotlib
- Google Colab
- GitHub
- Jira

## Funcionalidades implementadas

El script desarrollado permite:

- importar datos desde un archivo CSV
- calcular ventas totales
- identificar el producto más vendido
- calcular ventas por mes
- generar un gráfico de evolución de ventas
- guardar resultados dentro de la carpeta `/resultados`

## Instrucciones de ejecución

1. Abrir Google Colab.
2. Clonar el repositorio.
3. Ejecutar el archivo `analisis_ventas.py`.
4. Revisar los resultados generados.

## Resultados obtenidos

El análisis genera un gráfico de ventas mensuales que se guarda automáticamente en la carpeta `/resultados`.
